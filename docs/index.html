Narrative Conversation System

Tools

  • Editor: build a conversation from nodes, choices, and flags, then export it as JSON.
  • Player: load a conversation JSON file, set global flags, and play through it.
  • Example conversation JSON

Format

A conversation file has a title, a start node ID, a flags registry of shared boolean flags with initial values, and an array of nodes. Each node has an id, speaker, text, next, and choices. Each choice has text, target, conditions, and action.

See the repository README for the full specification.
