Narrative Conversation System

Tools

  • Editor: build a Story from Nodes and Choices, then export it as JSON. The editor registry is stored separately.
  • Player: load Story JSON, register typed facts in the player, and play through it.
  • Example Story JSON

Format

A Story has a start node ID and an array of nodes. Each Node has an id, speaker, text, and choices. Each choice has text, target, conditions, and action.

Conditions are arrays of objects with a fact, comparison, and one typed value (intValue, floatValue, stringValue, or boolValue). All Conditions must pass. An empty array is unconditional. An Action contains fact, action (update, delete, add, or subtract), and one typed value, except delete has no value. Use null for no action.

Fact registries and values are owned by the tools or host runtime, never the Story JSON. For the example, register accepted_task and read_report as false, or use the tools' "Register referenced facts with default values" button.

Every transition requires the player to select a Choice, including a single "Continue" Choice. An empty Choices array ends the Story.

See the repository README for the full specification.
