# Narrative Conversations and Barks

Source-based UPM package for Unity 6.0 and newer.

- `Videlais.Narrative`: engine-independent JSON models, typed facts, conversation and bark sessions.
- `Videlais.Narrative.Unity`: ScriptableObject initial-fact definitions.
- Dependency: Unity's Newtonsoft JSON package, installed by UPM.

See [package documentation](Documentation~/index.md) for installation and usage.
The repository README contains the complete JSON contracts and registry-adapter guidance.
